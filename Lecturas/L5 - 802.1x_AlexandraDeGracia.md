L5-802. 1X

Desarrollo

1. ¿Cómo funciona el Port-Based Authentication?

El Port-Based Authentication funciona comprobando la identidad de una persona o dispositivo antes de permitirle acceder a la red.
Primero se solicitan los datos necesarios para verificar quién intenta conectarse. Si la información es correcta y está autorizada,
se permite el acceso a la red. Si no se puede comprobar su identidad, el acceso no es permitido. De esta manera, se tiene un mayor 
control sobre las conexiones.

2. Defina los componentes principales de 802-1x.

Los principales componentes de 802.1X son el usuario o dispositivo que intenta conectarse, el equipo que controla el acceso 
y el sistema encargado de verificar la identidad. El usuario proporciona sus credenciales, el equipo de red controla la conexión
y el sistema de autenticación comprueba si los datos son correctos. Los tres trabajan en conjunto para decidir si se permite o no el acceso a la red.

3. ¿Por qué considera que este tipo de autenticación es relevante?

Considero que este tipo de autenticación es relevante porque ayuda a mantener la seguridad de una red y controlar quién puede acceder a ella. 
Es una forma de evitar que cualquier persona o dispositivo pueda conectarse sin autorización. Además, permite que las 
organizaciones tengan un mayor control sobre los usuarios que utilizan sus redes y sus recursos, 
lo cual es importante para proteger la información.[1]

Conclusión

En conclusión, el Port-Based Authentication y 802.1X son importantes para proteger el acceso a una red. 
A través de la verificación de la identidad, se puede controlar quién tiene permiso para conectarse y
evitar accesos no autorizados. Considero que conocer este funcionamiento es importante porque ayuda 
a comprender cómo se puede mantener una red más segura y controlada.
