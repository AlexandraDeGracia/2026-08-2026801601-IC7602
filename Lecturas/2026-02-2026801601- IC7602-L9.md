Preguntas:

1. ¿Qué es un firewall? Comente los tipos existentes en capa 3/4.

Un firewall es un sistema de seguridad que se coloca entre una red interna y una red externa, como Internet. Su función principal es controlar el tráfico que entra y sale de la red, permitiendo las conexiones que están autorizadas y bloqueando las que pueden representar algún riesgo.

En las capas 3 y 4 se puede utilizar el filtrado de paquetes. En este caso, el firewall revisa información como las direcciones IP, los protocolos y los puertos para decidir si un paquete puede pasar o debe ser bloqueado. De esta manera, se puede controlar qué comunicaciones tienen permitido entrar o salir de la red.

2. ¿Qué es un Bastion Host?

Un Bastion Host es un equipo que se prepara especialmente para cumplir una función de seguridad dentro de una red. Normalmente está más expuesto al tráfico que viene de redes externas, por lo que debe estar bien configurado y protegido.

Además, debe tener solamente los servicios que sean necesarios para cumplir su función. Esto ayuda a reducir los posibles riesgos, ya que si el equipo tiene demasiados servicios o configuraciones innecesarias, podría convertirse en un punto débil de la red.

3. ¿En qué consiste una DMZ?

Una DMZ o zona desmilitarizada es una red que se encuentra entre la red interna y la red externa. Se utiliza principalmente para colocar servidores o servicios que necesitan ser accesibles desde Internet, sin ponerlos directamente dentro de la red interna.

Por ejemplo, una empresa puede colocar su servidor web en la DMZ para que los usuarios de Internet puedan acceder a él. De esta manera, si ese servidor llegara a ser atacado, existe una separación entre él y los demás equipos de la red interna.

4. ¿Qué es un Proxy Server?

Un Proxy Server es un servidor que funciona como intermediario entre los equipos de una red interna y los servicios que se encuentran fuera de ella.

Por ejemplo, cuando un equipo de la red interna quiere acceder a un sitio de Internet, en lugar de comunicarse directamente con ese sitio, la solicitud pasa primero por el proxy. El proxy se encarga de realizar la comunicación y esto permite tener un mayor control sobre las conexiones que se realizan.

Por esta razón, un proxy también puede utilizarse como parte de la seguridad de una red, ya que ayuda a controlar las comunicaciones entre los usuarios internos y el exterior.

5. Explique los diferentes protocolos de VPN.

Los protocolos de VPN se utilizan para establecer comunicaciones más seguras a través de redes públicas como Internet. Cada uno tiene una función diferente dentro de la comunicación.

IPSec: se utiliza para proteger las comunicaciones IP. Permite proporcionar seguridad a los datos mediante mecanismos de autenticación, integridad y cifrado.

ESP: es parte de IPSec y se utiliza principalmente para cifrar los datos, evitando que una persona que intercepte la comunicación pueda leerlos. También puede proporcionar autenticación e integridad.

AH: también forma parte de IPSec. Su función principal es proporcionar autenticación e integridad, permitiendo comprobar que los datos no hayan sido modificados durante la comunicación.

IKE: se utiliza para establecer los parámetros de seguridad y realizar el intercambio de las claves necesarias para proteger la comunicación mediante IPSec.

PPTP: permite crear un túnel para establecer una conexión VPN utilizando una red pública como Internet.

También existen algunas tecnologías que se relacionan con la autenticación y el manejo de usuarios en las VPN:

X.509: se utiliza para los certificados digitales, que permiten comprobar la identidad de los participantes en una comunicación.

LDAP: permite consultar información almacenada en servicios de directorio, como información de usuarios.

RADIUS: se utiliza principalmente para autenticar y autorizar a los usuarios que intentan acceder a determinados recursos de la red.
