Preguntas:

1. ¿Qué es un firewall? Comente los tipos existentes en capa 3/4.

Un firewall es un sistema de seguridad que se coloca entre una red interna y una red externa, como Internet. Su función es controlar el tráfico que entra y sale de la red, permitiendo las conexiones autorizadas y bloqueando las que puedan representar un riesgo.

En las capas 3 y 4 se puede utilizar el filtrado de paquetes, donde el firewall revisa información como las direcciones IP, los protocolos y los puertos para decidir si un paquete puede pasar o debe ser bloqueado.

Entre los tipos de firewall mencionados en el libro se encuentran los routers de filtrado de paquetes, los Bastion Hosts, las DMZ o redes perimetrales y los Proxy Servers. Estos mecanismos permiten controlar y proteger las comunicaciones entre la red interna y las redes externas.

2. ¿Qué es un Bastion Host?

Un Bastion Host es un equipo que se prepara especialmente para cumplir una función de seguridad dentro de una red. Generalmente se encuentra expuesto al tráfico proveniente de redes externas, por lo que debe estar correctamente configurado y protegido.

Este equipo debe tener únicamente los servicios necesarios para cumplir su función y debe estar asegurado para reducir los posibles riesgos. Además, puede trabajar junto con un sistema de filtrado de paquetes para controlar el tráfico entre la red interna y la externa.

3. ¿En qué consiste una DMZ?

Una DMZ o zona desmilitarizada es una red que se encuentra entre la red interna y la red externa. Su función es crear una separación entre ambas redes y permitir colocar en ella equipos o servicios que necesitan ser accesibles desde el exterior.

Por ejemplo, una empresa puede colocar un servidor que debe ser accesible desde Internet dentro de la DMZ. De esta manera, este servidor queda separado de la red interna, reduciendo el riesgo de que un problema en ese equipo afecte directamente a los demás equipos de la organización.

4. ¿Qué es un Proxy Server?

Un Proxy Server es un servidor que funciona como intermediario entre los equipos de una red interna y los servicios que se encuentran fuera de ella.

Cuando un equipo interno necesita comunicarse con un servicio externo, la solicitud puede pasar primero por el proxy. Este realiza la comunicación en nombre del equipo interno y permite controlar el tráfico que pasa entre ambas redes.

Por esta razón, un Proxy Server también puede utilizarse como parte de la seguridad de una red, ya que ayuda a controlar las comunicaciones y puede evitar que los equipos internos tengan una comunicación directa con el exterior.

5. Explique los diferentes protocolos de VPN.

Los protocolos y tecnologías de VPN se utilizan para establecer comunicaciones seguras a través de redes públicas como Internet. Cada uno cumple una función diferente dentro de la comunicación.

IPSec: es un conjunto de protocolos utilizado para proteger las comunicaciones IP. Puede proporcionar autenticación, integridad y confidencialidad de los datos.

ESP: forma parte de IPSec y se utiliza principalmente para proporcionar confidencialidad mediante el cifrado de los datos. También puede proporcionar autenticación e integridad.

AH: también forma parte de IPSec y proporciona principalmente autenticación e integridad, permitiendo comprobar que los datos no hayan sido modificados durante la comunicación.

IKE: se utiliza para establecer los parámetros de seguridad y realizar el intercambio de claves necesarias para establecer una comunicación protegida mediante IPSec.

PPTP: permite crear un túnel para transportar comunicaciones a través de una red pública como Internet y establecer una conexión VPN.

También existen tecnologías relacionadas con la autenticación y el manejo de usuarios:

X.509: se utiliza para los certificados digitales, que permiten verificar la identidad de los participantes en una comunicación.

LDAP: permite consultar y administrar información almacenada en servicios de directorio, como información relacionada con usuarios y certificados.

RADIUS: se utiliza para la autenticación y autorización de usuarios que intentan acceder a determinados recursos de la red.
