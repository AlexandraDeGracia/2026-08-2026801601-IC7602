L2 - Classification of Network Architectures

Preguntas:
1. Explique la diferencia entre una WAN y una MAN.

Una WAN (Wide Area Network) es una red que cubre un área geográfica extensa, pudiendo conectar redes ubicadas en diferentes ciudades,
regiones o países. En cambio, una MAN (Metropolitan Area Network) cubre un área más limitada, normalmente una ciudad o una zona metropolitana. 
Por lo tanto, la principal diferencia es el alcance geográfico: la WAN tiene una cobertura mayor que la MAN.

2. Explique las diferencias entre una red orientada a conexión y una red no orientada a conexión.

Una red orientada a conexión establece primero una conexión o ruta entre los dispositivos antes de comenzar a transmitir los datos. 
Una vez establecida, la comunicación utiliza esa conexión durante la transferencia.
Una red no orientada a conexión no necesita establecer una conexión previamente.
Los datos pueden enviarse directamente y cada paquete puede ser tratado de manera independiente, pudiendo seguir diferentes rutas hasta llegar al destino.

3. ¿Qué es una red punto a punto? Explique cómo implementarla de acuerdo con la lectura.

Una red punto a punto (point-to-point) es una conexión directa entre dos dispositivos, en la que existe un enlace dedicado para comunicar un extremo con el otro.

Para implementarla, se establece un enlace directo entre los dos dispositivos, utilizando un medio de transmisión, como un cable. 
De esta manera, los dos puntos pueden intercambiar información directamente sin tener que compartir el enlace con otros dispositivos. 
La lectura también muestra representaciones de conexiones entre computadoras y diferentes topologías de red.

4. Explique los conceptos de FDM y TDM.

FDM (Frequency Division Multiplexing) o multiplexación por división de frecuencia consiste en dividir el ancho de banda disponible de un enlace en diferentes rangos o canales de frecuencia. Cada comunicación utiliza una frecuencia diferente, permitiendo que varias transmisiones ocurran simultáneamente.

TDM (Time Division Multiplexing) o multiplexación por división de tiempo consiste en compartir la capacidad de un enlace dividiendo el 
tiempo en diferentes intervalos o timeslots. Cada transmisión utiliza el enlace durante un intervalo de tiempo determinado. En la lectura 
se muestran precisamente los conceptos de bandwidth, FDM, Link Capacity y Timeslot.
